Daily

A morning dashboard for a jailbroken Kindle: top news by category, markets and weather.

Install over USB (easiest, no terminal)

  1. Download daily-kindle.zip.
  2. Connect the Kindle to your computer and unzip the file at the root of the Kindle drive (you get a daily-install folder and documents/install-daily.sh). Eject the Kindle.
  3. In your Kindle library, tap Install Daily once. A message at the bottom of the screen says when it's done.
  4. Open Daily from your library.

To update later, repeat with the new zip.

Install with KPM (terminal)

kterm doesn't know the short kpm command, so use its full path:

  1. In the Kindle search bar: ;kpm install kterm, then open kterm.
  2. In kterm: /var/local/kmc/bin/kpm add-repo https://vimalnaugain.github.io/kindle-daily/app/manifest.json
  3. Then: /var/local/kmc/bin/kpm update and /var/local/kmc/bin/kpm install daily
  4. Open Daily from your Kindle library.

If that path doesn't exist either, run ls /var/local/kmc/bin /mnt/us/kmc/bin in kterm to find kpm.
