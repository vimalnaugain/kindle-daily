Daily

A morning dashboard for a jailbroken Kindle: top news by category, markets and weather.

Install with KPM

  1. In the Kindle search bar: ;kpm install kterm, then open kterm.
  2. In kterm, once: kpm add-repo https://vimalnaugain.github.io/kindle-daily/app/manifest.json then kpm update
  3. In the search bar: ;kpm install daily. Later updates: ;kpm upgrade
  4. Open Daily from your Kindle library.

Install over USB (KUAL)

Unzip daily-kindle.zip at the root of the Kindle drive, eject, and start Daily from KUAL.
